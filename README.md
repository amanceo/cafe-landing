# ☕ Morning Leaf Café 랜딩 페이지

가상의 카페 **"모닝리프(Morning Leaf)"**를 소개하는 한 페이지짜리 웹사이트예요.
AI 에이전트 수업에서 Claude Code로 웹 페이지를 만들고 GitHub에 올리는 과정을 연습하려고 만든 예제 프로젝트예요.

## 이 폴더는 무엇인가요?

별도의 프레임워크나 빌드 도구 없이 **HTML과 CSS만으로** 만든 정적 웹 페이지예요.
파일을 내려받아 브라우저로 열기만 하면 바로 볼 수 있어요.

## 페이지 구성

| 섹션 | 내용 |
| --- | --- |
| 상단 메뉴 | 로고, 소개·메뉴·오시는 길로 이동하는 링크 (스크롤해도 따라와요) |
| 첫 화면 | 카페 소개 문구, "메뉴 보기" 버튼, 김이 올라가는 커피잔 애니메이션 |
| 소개 | 직접 로스팅 · 매일 굽는 빵 · 머무르고 싶은 공간, 카드 3개 |
| 대표 메뉴 | 커피와 디저트 6가지, 가격 |
| 오시는 길 | 주소, 영업시간, 연락처 |
| 하단 | 저작권 표시 |

## 파일 구조

```
cafe-landing/
├── index.html   # 페이지 구조와 내용
├── style.css    # 색상, 글꼴, 레이아웃, 애니메이션, 모바일 대응
└── README.md    # 지금 보고 있는 설명 파일
```

## 특징

- **반응형 디자인**: 화면 폭이 760px 이하면 모바일 레이아웃으로 바뀌어요
- **CSS만으로 만든 일러스트**: 커피잔과 김 애니메이션을 이미지 없이 CSS로 그렸어요
- **색상 변수**: `style.css` 맨 위 `:root`의 색상 값만 바꾸면 전체 분위기를 바꿀 수 있어요
- **글꼴**: Google Fonts의 Gowun Batang(제목)과 Noto Sans KR(본문)을 써요

## 실행 방법

1. 이 레포를 내려받아요
   ```bash
   gh repo clone amanceo/cafe-landing
   ```
2. `index.html` 파일을 더블클릭해서 브라우저로 열어요

## 참고

카페 이름, 주소, 전화번호, 메뉴는 모두 예시로 지어낸 정보예요.
